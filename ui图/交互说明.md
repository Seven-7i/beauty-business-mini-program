# 交互说明

> 更新时间：2026-07-22

## 1. 通用规则

- 路由页面作为组合层，表单、选择器、列表、状态操作和确认弹层拆成聚焦组件。
- 表单草稿仅由当前页面持有；快速新增顾客、项目或库存物品返回后，原草稿不得丢失。
- 字段错误紧邻字段显示，首次提交定位到第一个错误。
- 保存、删除、状态变更、导出和恢复期间禁用重复点击。
- 成功使用短 Toast；失败说明原因和下一步，不清空表单。
- 返回前存在未保存修改时确认“放弃本次编辑？”。
- 删除、完成、撤销完成、取消、恢复取消和整体恢复使用明确动词的确认弹层。
- 所有业务页面遵守无媒体约束，不显示或上传业务图片、头像、照片、视频和附件。

## 2. 启动、模块与工作台

| 场景 | 反馈与去向 |
| --- | --- |
| 尚未解锁模块 | 展示模块码输入和“从备份恢复”；`587960` 解锁美容模块。 |
| 授权码无效或重复 | 保留输入，分别提示“授权码无效”或“该模块已解锁”。 |
| 只有一个模块 | 直接进入该模块，不展示默认模块设置。 |
| 多个模块且无默认项 | 展示模块选择页。 |
| 多个模块且有默认项 | 直接进入默认模块，仍可手动切换。 |

第一版只允许添加模块，不提供移除入口。工作台显示模块入口和近期预约；美容首页显示本月完成数、本月成交金额、待执行数，以及全部逾期、今天和未来三天的预约。

## 3. 库存物品

### 3.1 列表与表单

- 列表支持按名称搜索、启用/停用筛选和新增，行内展示名称、单位、当前库存、占用和可用库存。
- 新增填写名称、单位、初始库存和选填备注；启用对象的“名称 + 单位”不可重复。
- 离散单位使用整数输入，连续单位允许最多两位小数。
- 已被引用的物品不能修改单位，只能停用后新建。
- 已被引用的物品只能停用；未被引用的物品可以二次确认后删除。

### 3.2 库存调整

- “补货”填写增加数量；“盘点修正”填写盘点后的实际数量。说明均选填。
- 系统展示变动前、差额和变动后数量，并生成库存变动记录。
- 手工记录允许编辑或删除，但不得使库存为负或低于待执行预约占用。
- 预约消耗记录只读，点击来源可以进入预约；来源预约已删除时显示“来源预约已删除”。

## 4. 项目

- 列表展示唯一名称、标准价格、预计时长、默认物品数和状态。
- 表单中标准价格必填且允许 0 元；预计时长必填，提供 30/60/90/120 分钟快捷项。
- 默认物品用量可以为空；每项数量大于 0 并遵循单位精度。
- 选择物品时可快速新增，保存后自动选中并保留项目草稿。
- 已被预约引用的项目只能停用；未被引用的项目可以删除。

## 5. 顾客与地址

- 顾客列表支持昵称和手机号搜索，完整显示手机号，不脱敏。
- 昵称和中国大陆 11 位手机号在全部未删除顾客中分别唯一；停用后仍占用。
- 顾客可以维护多个服务地址，每项包含地址正文和地址备注，不设置默认地址。
- 已有预约的顾客只能停用；未关联预约的顾客可以删除。
- 顾客详情展示当前资料、地址、历史预约、累计完成次数和累计成交金额。
- 预约中快速新增顾客成功后自动选中；重名或重复手机号时引导查看已有顾客。

## 6. 预约创建与编辑

1. 选择一个顾客；找不到时可快速新增。
2. 选择至少一个互不重复的项目；找不到时可快速新增。
3. 系统汇总标准金额、预计总时长和默认物品用量。
4. 用户可以添加、移除或修改本次实际用量。数量不能超过排除预约自身后的可用库存。
5. 项目组合发生任何变化时，已有实际用量全部覆盖，并按新项目重新生成；标准金额和预计总时长同步更新。
6. 手动选择顾客服务地址或填写临时地址；临时地址可选择同时保存给顾客。地址必填。
7. 选择预约开始时间，填写选填备注后保存。

时间与另一待执行预约重叠时展示冲突明细，用户可以取消或确认继续；只计算服务时段，不计算路程。改期直接编辑原待执行预约。

## 7. 预约状态操作

### 待执行

- 占用但不扣减库存。
- 计划时间已过时派生显示“已逾期”并置顶，不自动改变状态。
- 可以编辑、改期、完成、取消或删除。
- 删除表示误建，二次确认后释放占用；真实取消使用取消操作。

### 完成

点击“完成预约”进入确认页，编辑实际物品用量、成交金额、实际完成时间和备注。成交金额默认带出标准金额，完成时间默认当前时间。库存不足时禁止确认并显示缺少数量。

完成后允许更正上述四项；更正用量自动补回或补扣库存。顾客和项目不能直接替换。误点完成时使用“撤销完成”，补回库存并恢复待执行占用。

删除已完成预约不会补回库存；库存消耗记录继续保留，经营统计移除该预约。

### 取消

取消原因选填，可使用“顾客取消、时间冲突、改期、其他”等快捷项。取消后释放占用。

误取消时可恢复待执行；库存不足则阻止恢复并显示缺少数量。已取消记录可二次确认后删除，不改变库存。

## 8. 月历与提醒

- 月历标记存在预约的日期，点击日期展示当天列表；不做拖拽、周视图或时间轴。
- 第一版只有应用内提醒，不发送微信消息。
- 首页提醒区显示全部逾期、今天和未来三天的预约。

## 9. 备份、容量与恢复

### 七天提醒

- 有业务数据且距首次数据或最近导出满七个自然日时提醒。
- 周期不可关闭或修改；“稍后”后同一自然日不再出现，第二天仍到期则继续提醒。

### 导出

1. 首次导出提示未加密文件包含顾客资料。
2. 生成带格式版本和完整性校验的 JSON，并拉起微信文件转发。
3. 用户手动选择联系人；小程序不读取通讯录、不预选或自动发送。
4. 成功后显示并记录“最近导出时间”；取消或失败不更新。

### 恢复

- 激活页和“我的”均可选择备份文件。
- 校验通过后展示文件时间、版本和数据摘要。
- 已有数据时提供“先导出当前数据”和“我已了解，继续恢复”。
- 恢复整体替换业务数据、模块授权和设置；失败保持当前数据不变。
- 旧版备份迁移后恢复；未来版本提示升级；未知或损坏文件拒绝恢复。

### 容量

- 达到 7MB 时显示导出和手动清理提示，不自动删除数据。
- 历史清理按日期和状态筛选；各状态删除后的库存语义按需求文档执行。
