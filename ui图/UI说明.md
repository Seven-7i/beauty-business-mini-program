# 小程序 UI 图说明

> 更新时间：2026-08-28
> 图稿只表达视觉方向；字段、状态和行为以 `docs/微信小程序需求文档.md` 与《交互说明.md》为准。

## 当前全局页面图稿

工作台定稿为 `13-工作台-模块门厅-无管理入口-v5.png`；“我的”定稿为 `12-我的-本机控制中心-v1.png`。两者共同约束全局应用层页面，不向美容等具体业务模块扩散。

- 工作台定位为独立的“模块门厅”，只负责展示和进入业务模块，不继承任何具体业务模块的风格。
- 使用暖石色底、墨色文字、靛灰平台色和低饱和玫瑰色模块标识。玫瑰色只用于美容模块局部，不作为工作台全局主题色。
- 通过半透明面板、背景模糊、柔和环境色块、细描边和分层阴影建立 Apple 式空间层次；禁止用照片或纹理图模拟高斯模糊。
- 工作台不展示美容模块的“待处理”数据；模块业务数据进入对应模块后查看。
- 工作台不展示数据保护入口；数据导出、恢复和容量管理统一放在“我的”。
- 工作台不再提供“模块管理”入口；模块管理统一放在“我的”的“数据与管理”分组中。
- 底部工作台图标使用统一靛灰线条小房子，选中态由磨砂底和颜色表达，不使用黑色实心块。

### “我的”当前方向

- “我的”与工作台使用同一套暖石色背景、半透明磨砂面板、环境色块、细描边和分层阴影，不另设全局主题。
- 页面定位为本机控制中心，不展示账号资料、头像或社交身份；首要信息是本机存储状态。
- 数据备份与恢复、模块管理和使用说明集中在“数据与管理”分组中，使用统一线条图标和轻量右箭头。
- 底部导航结构与工作台保持一致，仅切换“我的”的选中态。
- `12-我的-本机控制中心-v1.png` 已确认并进入代码实现。

### “数据备份与恢复”当前方向

- `14-数据备份与恢复-本机数据保护-v1.png` 是从“我的”进入的系统级子页面定稿，延续同一套暖石色磨砂空间风格，不设置底部全局导航，已进入代码实现。
- 首屏先展示“最近完整系统导出”，让用户立即判断是否需要备份；导出区明确区分“完整系统备份”和“选择模块导出”。
- 两个导出卡片行本身是入口，行尾统一使用箭头；点击后先确认范围与未加密风险，再生成文件，不使用选择后动态出现的“立即导出”按钮。
- 微信转发返回后使用强确认弹窗询问实际发送结果；若未处理便退出，下次进入程序再次弹出“上次导出尚未确认”，不会仅依赖页面内弱提示。
- “已发送”一经本机保存便不可改回“未发送”；后续异常只提供完成记录的单向重试，避免最近导出状态与用户决定相互矛盾。
- 冷启动确认采用单次门禁：同一条待确认只打开一个弹窗，处理后本次启动不再紧接容量或七天提醒。
- 恢复入口单独成卡，先选择并校验文件，再进入范围摘要与覆盖确认；页面不使用“合并”“云端同步”或“加密备份”等错误暗示。
- 未加密文件风险使用低干扰提示卡常驻说明；真正导出或恢复前仍按交互规则进行明确确认。

## 运行时零图片约束

- 产品运行界面不使用 PNG、JPG、WebP、照片、头像、缩略图、纹理图或图片背景，也不使用 `<image>` 承载功能图标。
- 微信编译产物同样不得包含 `data:image/*` 内嵌位图或指向位图文件的 CSS `url()`；不为单个控件引入带默认图片资源的整套 UI 组件库。
- 图标通过统一的 `AppIcon` 语义组件封装随包内置的精简 Iconfont，调用方只使用 `home`、`account`、`storage`、`backup`、`history`、`file-restore`、`shield`、`modules`、`info`、`chevron-right` 等语义名称；微信小程序端不依赖图片、SVG、远程字体或 Iconfont CDN。
- `AppIcon` 使用统一 1000 单位字形画布和组件行盒；字体文件、字符映射均由 `scripts/generate-icon-font.mjs` 生成，不同页面不得接触码位或各自修正图标位置。
- “我的”和系统级数据保护页的线条图标直接落在卡片内容区，不额外叠加彩色圆角底座；最近完整系统导出使用标准单圈时钟，不叠加回环、虚线尾巴或第二层圆环。
- 六位模块授权码使用项目自有的 `ModuleCodeInput` 纯 Vue/CSS 组件，不依赖带图片默认配置的第三方输入组件。
- 高斯模糊、环境光、层次和装饰图形只能由 CSS 颜色、透明度、模糊、描边和阴影生成。
- `ui图` 中的 PNG 仅用于开发评审，不进入小程序运行包。

## 视觉语言

- 工作台、“我的”及其系统级子页面使用上述统一的暖石色空间风格；模块管理后续单独定稿，备份恢复 v1 已确认并进入代码实现。
- 美容模块使用浅粉、雾紫和鼠尾草绿的轻美容风格；毛玻璃只用于概览卡、模块卡和弹层，表单与高频列表使用高不透明度实体面板。
- 所有业务列表和详情均使用纯文字信息布局，不展示产品图、包装图、顾客头像、照片、缩略图或图片占位，也不提供媒体上传入口。
- 搜索、返回、日历等明确操作可以使用随应用打包的功能图标；图标不写入业务记录或备份。

## 图稿自动维护规则

- 每个页面只长期保留一张已确认定稿；正在评审时，额外保留该页面最新一张候选稿。
- 新候选稿生成后自动删除同页面已淘汰且未确认的旧版本；确认新稿后，用新稿替换旧定稿索引。
- 删除图稿前核对文件名和页面归属；`UI说明.md` 必须同步更新当前状态、关键决策和图稿索引。
- 图稿删除不代表删除需求；字段、状态和交互规则始终以需求文档和《交互说明.md》为准。
