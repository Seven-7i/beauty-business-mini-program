# 小程序 UI 图说明

> 更新时间：2026-07-22  
> 图稿只表达视觉方向；字段、状态和行为以《微信小程序需求文档.md》与《交互说明.md》为准。

## 视觉语言

- 工作台、模块管理、我的、备份与恢复使用暖白底、深灰文字、靛蓝操作色和实体卡片的中性效率工具风格。
- 美容模块使用浅粉、雾紫和鼠尾草绿的轻美容风格；毛玻璃只用于概览卡、模块卡和弹层，表单与高频列表使用高不透明度实体面板。
- 所有业务列表和详情均使用纯文字信息布局，不展示产品图、包装图、顾客头像、照片、缩略图或图片占位，也不提供媒体上传入口。
- 搜索、返回、日历等明确操作可以使用随应用打包的功能图标；图标不写入业务记录或备份。

## 图稿索引与解释

### 01-模块解锁与设置.png

首次输入模块码、解锁成功、多模块选择和默认模块设置的概念稿。第一版模块只允许增加，不提供移除入口；单模块时不显示默认模块设置。

### 02-首页与物品采购-v3.png

对应美容首页、库存物品列表、新增和详情。图名中的“物品采购”是旧术语，产品界面统一显示“库存物品”。

旧图中的金额或采购单价不再使用。库存物品以名称、单位、当前库存、占用、可用库存、状态和备注识别；详情增加补货、盘点修正和库存变动入口。

首页展示本月完成预约数、本月成交金额、待执行预约数，以及全部逾期、今天和未来三天的预约。

### 03-项目与顾客-v3.png

对应项目列表、项目表单、顾客列表和顾客详情。

- 项目字段为唯一名称、标准价格、预计服务时长和可选的默认物品用量。
- 顾客字段为唯一昵称、中国大陆 11 位唯一手机号和多个服务地址；手机号完整显示，不脱敏。
- 每个服务地址包含地址正文和备注，不设置默认地址。
- 顾客详情展示历史预约、累计完成次数和累计成交金额。

### 04-预约执行-v2.png

对应预约列表、预约表单、快速新增、详情和执行操作。旧图中的单项目、折扣字段和“约定金额”不再使用。

- 一次预约选择一个顾客和一个或多个互不重复的项目。
- 待执行阶段显示标准金额，不填写成交金额。
- 完成确认时填写实际用量、成交金额、实际完成时间和备注。
- 新增表单必须选择服务地址，可从顾客地址列表手动选择或填写临时地址。
- 预约支持完成、撤销完成、取消、恢复取消及按规则删除。

### 05-工作台首页与模块管理-v2.png

对应全局工作台、模块管理、我的和数据保护入口。“最近备份”文案统一改为“最近导出”。

### 06-模块解锁与初始引导-v2.png

对应模块码 `587960`、解锁成功、单模块直达和多模块选择。模块激活页同时提供“从备份恢复”入口。

### 07-备份与恢复交互.png

对应七天提醒、未加密 JSON 生成、微信手动转发和整体恢复确认。

- 到期后同一自然日最多提醒一次。
- 恢复已有数据前提供“先导出当前数据”和“我已了解，继续恢复”。
- 新设备可从激活页完整恢复业务数据、已解锁模块和个人设置。
