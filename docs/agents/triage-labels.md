# 分诊标签

Matt Pocock 的技能使用五种固定的分诊角色。本文件把这些角色映射为本仓库 GitHub Issues 中的实际标签。

| 技能中的角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给自动化代理处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 确认不处理 |

当技能提到某个分诊角色时，应使用表格中对应的 GitHub 标签。若以后修改仓库的标签命名，只需更新右侧的“GitHub 标签”列。
